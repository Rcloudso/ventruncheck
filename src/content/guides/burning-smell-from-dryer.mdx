## The problem

A burning smell from a dryer is easy to minimize as “first-use dust,” “new clothes,” or “the heating element always smells.” Sometimes that is harmless dust on a brand-new machine. Often it is **heat trapped against lint** in a restricted vent, a crushed transition hose, or debris at the outdoor cap. Running “one more load to see if it goes away” is how people turn a warning into a fire risk.

This page is a **stop → inspect → decide** guide. It is not a fire-department inspection, insurance claim form, or brand-specific repair manual.

**Safety first:** If you smell burning, see smoke, scorched or brown lint, glowing spots, or the dryer cabinet feels unusually hot, **stop using the dryer now**. Unplug it or switch off the breaker. Do not run another cycle to “confirm” the smell. Long, attic, or roof-terminated runs you cannot safely reach belong with a qualified pro — not deeper DIY probing into the duct.

## Decision tree

Work top to bottom. The first matching row wins.

1. **Smoke, visible flame, glowing metal, or the smell keeps getting stronger mid-cycle?** → **Stop and power off immediately.** Leave the area if smoke is heavy and call emergency services if needed. Do not open the dryer door into a smoke-filled room as a first move; do not brush or blow into the duct until a qualified person has inspected.
2. **Burning or hot-plastic / scorched-lint smell, brown lint at the screen or behind the dryer, or a cabinet that is much hotter than usual?** → **Stop the dryer.** Treat as a heat + lint condition. Inspect the short path you can see (lint screen, behind-dryer hose, outdoor cap if ground-level and safe) only after power is off — then decide DIY vs pro.
3. **Smell only on the first few loads of a brand-new dryer, no smoke, normal dry time, outdoor flap moves with steady warm air?** → Often manufacturing oils/dust. Still stay home for those early loads; if smell returns later or dry time worsens, jump back to step 2.
4. **Smell plus slow drying, hot laundry room, or a weak outdoor flap?** → High odds of a **clogged or crushed vent path**. Clear/inspect the accessible ends, then plan a full-run clean. Symptom map: [signs of a clog](/ventruncheck/guides/signs-clogged-dryer-vent).
5. **Transition hose is foil, vinyl, kinked, or disconnected?** → Power off, reseat or replace with rigid/semi-rigid metal, then retest only after the path is continuous. See [metal vs foil](/ventruncheck/compare/metal-transition-vs-foil-duct) and [behind-the-dryer inspection](/ventruncheck/checklist/behind-the-dryer-inspection).
6. **Outdoor cap stuck, nested, or packed with lint mats?** → Clear or inspect the termination if it is ground-level and safe. A clear-looking hood with **weak** air still means a mid-run clog — related: [outdoor vent cap checklist](/ventruncheck/checklist/outdoor-vent-cap-inspection).
7. **Long run (~25+ ft equivalent), many elbows, attic/roof termination — DIY only reaches the ends?** → Prefer a **pro full-run clean** (dryer to outdoor termination) and a written scope. Do not “fix” a burning smell by pushing a leaf blower into an unknown duct — see [DIY vs pro](/ventruncheck/guides/diy-vs-pro-dryer-vent-cleaning) and [brush kit vs leaf blower](/ventruncheck/compare/brush-kit-vs-leaf-blower).
8. **After a documented full-run clear path + metal transition + open cap, smell or no-heat issues remain?** → Then appliance diagnosis (heating element, thermistor, wiring) is reasonable — the vent is no longer the cheap first suspect. Do not buy a new dryer first while the old vent is still suspect — see [check the vent before replacing](/ventruncheck/guides/dont-replace-dryer-check-vent-first).

## Smell vs next action

| Situation | Likely meaning | Sensible next step |
| --- | --- | --- |
| Smoke / flame / glowing spots | Active fire risk | **Stop**; power off; emergency help if needed |
| Scorched/brown lint + burning smell | Heat against lint | **Stop dryer**; inspect accessible path; pro if long/complex |
| Burning smell + two–three cycles / hot room | Restricted exhaust | Cap + transition + full-run airflow plan |
| Weak or stuck outdoor flap / lint mats | Cap clog, nest, or mid-run plug | Cap check if safe; else full run |
| Crushed foil/vinyl behind dryer | Kink trapping heat and lint | Replace with metal transition; retest dry time |
| New dryer, first loads only, good airflow | Often residual oils/dust | Monitor; stop if smell returns or worsens |
| Long/roof run, ends-only “clean” before | Incomplete scope | Pro dryer-to-termination clean, written scope |
| Path clear, still burns or no heat | Appliance-side fault possible | Qualified appliance diagnosis |

## Recommended types (not brands)

- **Stop-first habit** — burning smell is a power-off condition, not a “finish this load” condition.
- **Behind-the-dryer visual pass** — crushed hose, loose clamps, brown lint piles. Related: [behind-the-dryer inspection](/ventruncheck/checklist/behind-the-dryer-inspection).
- **Outdoor cap inspection** — flap motion and lint mats (ground-level only). Related: [outdoor vent cap checklist](/ventruncheck/checklist/outdoor-vent-cap-inspection).
- **Rigid or semi-rigid metal transition duct** — replace crushed foil/vinyl. Placeholder: [metal transition duct](/ventruncheck/resources?ref=PENDING#transition-duct).
- **Dryer vent drill brush kit** — short, accessible wall runs **after** the burning condition is resolved and only if the run is simple. Placeholder: [drill brush kit](/ventruncheck/resources?ref=PENDING#brush-kits).
- **Full-run professional cleaning** — written scope dryer → outdoor termination, especially for long/roof runs or any post-smell cleanup you cannot see end-to-end. Placeholder: [pro full-run cleaning](/ventruncheck/resources?ref=PENDING#pro-service).
- **Restart gate** — after any reconnect or clean, use [before you run the dryer again](/ventruncheck/checklist/before-you-run-the-dryer-again).

Avoid adding a booster fan to “push past” a smell or clog — see [booster fan vs cleaning](/ventruncheck/compare/booster-fan-vs-cleaning-clog). Avoid treating a leaf blower as proof the whole run is clear.

## Checklist

- [ ] Smell, smoke, scorched lint, or unusually hot cabinet? → **Stop the dryer** and cut power first.
- [ ] Do **not** run another load to confirm the smell.
- [ ] Note whether dry time was already slow, and whether the laundry room ran hot.
- [ ] Power off: check lint screen for brown/scorched lint (do not ignore it).
- [ ] Behind the dryer: crushed foil, kinks, loose joints, lint piles?
- [ ] Outside (if safe, ground-level): flap motion, nests, lint mats, weak airflow.
- [ ] Estimate run length / elbows / wall vs attic or roof termination.
- [ ] Short accessible run and smell source found at hose/cap? Fix metal transition / clear cap, then use the [before-you-run checklist](/ventruncheck/checklist/before-you-run-the-dryer-again).
- [ ] Long, roof, or unreachable mid-run — or smell with no obvious end clog? → Book a **pro full-run** inspection/clean; do not DIY deeper into the duct.
- [ ] Only after the vent path is documented clear and problems remain — book appliance diagnosis (not a blind dryer replacement).

A burning smell is a **stop signal**, not a shopping signal. Clear the heat path (or get a scoped pro clean on long runs) before you assume the machine itself is the whole story.
