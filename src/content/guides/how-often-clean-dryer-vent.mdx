## The problem

Most homeowners clean the lint screen every load and never touch the duct. Then clothes start taking two cycles, the laundry room feels hotter, or lint piles up at the outdoor cap. The question “how often?” gets vague answers (“once a year”) that ignore pets, heavy towel loads, and long vent runs — the exact cases where yearly is already late.

This page is a decision guide for interval planning, not a fire-code inspection or insurance guarantee.

**Safety first:** If you smell burning, see scorched lint, or the dryer cabinet is unusually hot, **stop using the dryer** and unplug it (or switch off the breaker). Do not wait for the next “scheduled” cleaning.

## Decision tree

1. **Burning smell, smoke, scorched lint, or unusually hot dryer exterior?** → **Stop the dryer now.** Inspect / call a qualified pro before any “routine” schedule matters.
2. **Clothes need multiple cycles, laundry room gets hot mid-cycle, or outdoor flap barely moves?** → Treat as **overdue** — clean now (DIY if short/accessible; pro if long/complex). Reset the clock after a full-run clean.
3. **Pets that shed, 8+ loads/week, or towels/bedding heavy weeks?** → Plan **every 6 months**, not yearly.
4. **Vent run longer than ~25 ft equivalent, 3+ hard bends, or roof termination?** → Prefer **pro full-run cleaning at least yearly**, with a mid-year DIY check of the outdoor cap and the short transition behind the dryer.
5. **Typical household (few loads/week, short wall vent, no pets)?** → **Once per year** is a reasonable baseline if you also clear the outdoor cap seasonally.
6. **Just moved in / never cleaned / unknown duct material?** → Clean **now**, then adopt the interval above. Ask whether any plastic or crushed foil sits behind the dryer.

## Interval table

| Situation | Suggested interval | Notes |
| --- | --- | --- |
| Typical use, short wall vent | About **12 months** | Still check outdoor cap a few times a year |
| Pets, heavy laundry, long towels/bedding weeks | About **6 months** | Lint and hair pack faster |
| Long run, many elbows, roof cap | **Yearly pro** + cap checks | DIY alone often misses mid-run plugs |
| New home / never cleaned | **Clean now**, then adopt row above | Don’t wait for the anniversary |
| After burning smell or scorched lint | **Before next load** | Schedule is irrelevant until cleared |

## Recommended types (not brands)

- **Annual (or 6-month) reminder habit** — calendar note tied to a season you already do home maintenance.
- **Outdoor cap inspection** — quick visual for lint mats, nests, stuck flaps (ground-level only if safe).

## Checklist

- [ ] No burning smell / scorched lint — if yes, stop dryer first.
- [ ] Pick your row in the interval table (pets? long run? never cleaned?).
- [ ] Put the next clean date on a calendar.
- [ ] Note wall vs roof termination and rough run length.
- [ ] After cleaning, run the [pre-use checklist](/ventruncheck/checklist/before-you-run-the-dryer-again) before the next load.
- [ ] If a pro quote only covers the first 6–12 ft on a long run, treat it as incomplete — see the DIY vs pro guide.

Yearly advice is a floor for simple setups, not a ceiling for heavy use or long ducts.
