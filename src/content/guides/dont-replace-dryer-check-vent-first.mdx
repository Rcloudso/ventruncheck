## The problem

When loads need two or three cycles, people often shop for a new dryer. Sales floors and “your machine is old” advice reinforce that. Many times the appliance still heats fine — **exhaust cannot leave**, so heat and moisture stay in the drum and the laundry room. You pay for a replacement, keep the same crushed foil hose or packed duct, and the new dryer “fails” the same way within months.

This page is a **replace vs inspect** decision guide. It is not a brand repair manual, warranty claim, or fire inspection checklist.

**Safety first:** If you smell burning, see scorched or brown lint, smoke, or the dryer cabinet feels unusually hot, **stop using the dryer** and unplug it (or switch off the breaker). Do not run “one more load” to confirm the smell, and do not buy a new unit to “solve” a burning smell — that is a stop-and-inspect condition. Long, attic, or roof-terminated runs you cannot safely reach belong with a qualified pro, not deeper DIY.

## Decision tree

Work top to bottom. The first matching row wins.

1. **Burning smell, smoke, scorched lint, glowing spots, or unusually hot dryer exterior?** → **Stop the dryer now.** Power off. Do not shop for a replacement as the first move — get a qualified inspection of the appliance **and** the vent path.
2. **Outdoor flap barely moves, stays shut, or you see thick lint mats / nests at the cap?** → Fix or clear the termination (ground-level only if safe) and retest dry time **before** buying a dryer. Related: [outdoor vent cap checklist](/ventruncheck/checklist/outdoor-vent-cap-inspection).
3. **Transition hose behind the dryer is crushed foil, vinyl, kinked, or disconnected?** → Reseat or replace with rigid/semi-rigid metal, then retest. See [metal vs foil](/ventruncheck/compare/metal-transition-vs-foil-duct) and [behind-the-dryer inspection](/ventruncheck/checklist/behind-the-dryer-inspection).
4. **Lint screen is clean every load, but drying time still doubled and the laundry room runs hot?** → Treat as a **full-run vent problem** until proven otherwise — not “buy a bigger dryer.” Symptom map: [signs of a clog](/ventruncheck/guides/signs-clogged-dryer-vent).
5. **Symptoms started right after moving, remodeling, or shoving the dryer tight to the wall?** → Look for a crushed transition or disconnected joint first; a new dryer will not fix a kink.
6. **Long run (~25+ ft equivalent), many elbows, attic/roof termination — DIY only reaches the ends?** → Prefer a **pro full-run clean** (dryer to termination) and retest dry time before replacement. Partial cleans of the first 6–12 ft are a common trap — see [DIY vs pro](/ventruncheck/guides/diy-vs-pro-dryer-vent-cleaning).
7. **After a documented full-run clean + metal transition + open cap, dry time is still bad and heat output is weak?** → Then appliance diagnosis (heating element, thermistor, blower) is reasonable — vent is no longer the cheap first suspect.

## Replace vs inspect table

| Situation | Likely first move | Buying a dryer first? |
| --- | --- | --- |
| Burning smell / scorched lint | **Stop dryer**; qualified inspection | No — not a shopping problem |
| Two–three cycles; hot laundry room | Cap + transition + full-run airflow check | No — vent first |
| Crushed foil / kink after a move | Fix transition hose | No |
| Weak outdoor flap / lint mats | Clear/inspect termination | No |
| Long/roof run, ends only cleaned before | Pro full-run clean, written scope | No until retest |
| New dryer already installed, same symptoms | Inspect vent path immediately | You may already own the wrong “fix” |
| Full-run clear, metal path, still no heat | Appliance diagnosis | Yes — vent ruled out |

## Recommended types (not brands)

- **Outdoor cap inspection habit** — seasonal flap motion and lint mats (ground-level only). Related: [outdoor vent cap checklist](/ventruncheck/checklist/outdoor-vent-cap-inspection).
- **Behind-the-dryer visual pass** — crushed hose, loose clamps, lint piles. Related: [behind-the-dryer inspection](/ventruncheck/checklist/behind-the-dryer-inspection).
- **Rigid or semi-rigid metal transition duct** — replace crushed foil/vinyl. Placeholder: [metal transition duct](/ventruncheck/resources?ref=PENDING#transition-duct).
- **Dryer vent drill brush kit** — short, accessible wall runs between pro visits. Placeholder: [drill brush kit](/ventruncheck/resources?ref=PENDING#brush-kits).
- **Full-run professional cleaning** — written scope dryer → outdoor termination, especially for long/roof runs. Placeholder: [pro full-run cleaning](/ventruncheck/resources?ref=PENDING#pro-service).
- **Interval planning** — after airflow is restored, set the next clean with [how often to clean](/ventruncheck/guides/how-often-clean-dryer-vent).

Avoid treating a leaf blower as proof the whole run is clear — see [brush kit vs leaf blower](/ventruncheck/compare/brush-kit-vs-leaf-blower). Do not add a booster fan to “save” a clogged duct — see [booster fan vs cleaning](/ventruncheck/compare/booster-fan-vs-cleaning-clog).

## Checklist

- [ ] No burning smell, smoke, or scorched lint — if yes, **stop the dryer** first; do not shop first.
- [ ] Note dry time: one cycle vs two/three for a normal load (same load size as before).
- [ ] From outside (if safe): does the flap open with steady warm air mid-cycle?
- [ ] Behind the dryer: crushed foil, kinks, loose joints, or vinyl hose?
- [ ] Lint screen clean — and still seeing heavy lint at the cap or on the floor?
- [ ] Estimate run length / elbows / wall vs roof or attic termination.
- [ ] Choose DIY (short accessible) or pro (long/complex) using the [DIY vs pro guide](/ventruncheck/guides/diy-vs-pro-dryer-vent-cleaning).
- [ ] After any clean or reconnect, run the [before-you-run checklist](/ventruncheck/checklist/before-you-run-the-dryer-again).
- [ ] Only after vent path is clear and dry time is still bad — then book appliance diagnosis or consider replacement.

Slow drying is often a **vent and heat-path** problem first. Rule that out with a short inspection (or a scoped pro clean) before you spend on a new dryer.
