## Side-by-side

| | Clean or fix the duct | Add a booster fan |
| --- | --- | --- |
| How it works | Remove lint packs, straighten crushed transitions, replace foil/vinyl with metal, clear the outdoor cap, restore a continuous path dryer → outdoors | An in-line fan pushes exhaust through a long or weak run after the dryer blower |
| Best setup | Known restriction: packed lint, kinked hose, stuck flap, or incomplete prior clean | Long equivalent length after the duct is already **clear**, metal, and code-compliant — fan is a last-mile assist, not a clog workaround |
| Pros | Fixes the root cause; lowers heat and fire load from trapped lint; often restores normal dry times without extra hardware | Can help legitimate long runs that stay within manufacturer duct limits once clear |
| Cons | Takes time or a pro fee; DIY may miss mid-run plugs | Masks a clog; can push heat/lint into a damaged chase; wiring, noise, and failure modes; may violate dryer or local rules if misapplied |
| Mess / maintenance | Lint removal mess once; then normal screen + seasonal cap checks | Fan needs power, cleaning access, and replacement; lint still builds if the duct is dirty |
| Skill / risk | Moderate DIY on short accessible runs; pro for long/roof/unknown chases | Higher — electrical + incorrect install on a restricted duct raises heat risk |

## When to pick each

**Pick clean or fix the duct when:**

- Dry times crept up, the laundry room runs hot, or the outdoor flap barely moves.
- You find crushed foil/vinyl, lint mats at the cap, or a nest — start there, not with a fan.
- A previous “clean” only reached the first few feet; symptoms returned.
- You smell burning or see scorched lint — **stop the dryer**; inspect/clean with qualified help before any add-on hardware.

**Pick a booster fan only when (narrow cases):**

- A full-run clean (dryer to termination) already happened and the duct is intact metal with open termination.
- The run is long enough that the dryer maker’s install guide still allows it **and** a listed dryer-vent booster is specified for that use.
- You can service the fan (access panel, power disconnect) and you are not using it to “force” air through a known clog.
- Local code / manufacturer instructions allow the product — if unclear, ask a qualified installer, not a shopping cart.

## Where each approach fails

**Cleaning / fixing fails when:**

- You only vacuum the lint screen and outdoor hood, then call the mid-run “done.”
- Foil duct tears or collapses and you leave it in place.
- Roof or multi-story runs are unreachable DIY — partial end cleans leave the plug in the middle.
- Joints stay loose and dump lint into the cavity after reassembly.

**Booster fan fails when:**

- The duct is still packed — the fan fights a plug, heats the airstream, and can drive lint into gaps.
- Foil/vinyl or crushed transitions remain; pressure finds the weak point.
- The fan is installed without cleaning access or fails mid-cycle with no one noticing dry times climbing again.
- It is sold as a substitute for fixing length, elbows, or a damaged chase that should be redesigned.

**Shared stop rules:** burning smell, smoke, or scorched lint → **stop using the dryer** and get qualified help. Do not add a booster “to see if heat goes away.” Long, roof-terminated, or unknown runs usually need a pro full-run clean before any fan discussion.
