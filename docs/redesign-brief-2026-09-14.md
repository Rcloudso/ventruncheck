## 1) 诊断：为什么「干」

| 问题 | 现状 |
| --- | --- |
| **无视觉锚点** | 首页只有 H1 + 一段 lede + 纯文字卡片；无英雄区、无插图、无图标 |
| **信息密度偏「长文博客」** | 正文字号 17px、行宽约 42rem，Guide 页是连续标题+列表，像纯 Markdown 预览 |
| **卡片弱** | `.card` 只有细边框+白底，无封面、无类型标签（Guide/Compare/Checklist）、无「读完能得到什么」短标签 |
| **配色克制过头** | 米灰底 + 单青绿 accent，层次少；导航 muted 灰色，品牌感弱 |
| **缺「工具感」** | 目录站应有决策入口（Start here / 按症状），现在是扁平列表堆标题 |
| **移动端尚可但无节奏** | 有基础响应式，但无 sticky 目录、无分段色块，滚动全是字 |

结论：内容方向对（铲子/决策），**外壳像未装修的 docs 草稿**，不是「难看字体」单点问题。

## 2) 视觉方向（一版）

**定位：** Quiet utility directory — 像简洁 docs + 信息卡（Wirecutter 卡片信息密度，但去掉评测站促销感）。

- **气质：** 干净、可信、家务工具书；青绿（已有 accent）升级为「通风/气流」主题色，加一档暖纸色表面
- **结构：** 首页 = 短英雄区 + 3 类入口（Guide / Compare / Checklist）+ 卡片网格（带类型 pill + 一行 outcome）
- **内页：** 保留现有 MDX 结构（Problem → Decision → Table → Types → Checklist）；只加顶部「本页你将得到」条、章节左侧或顶部 sticky mini-nav（可选）、表格/决策树更「卡」化
- **不做：** 大 hero 视频、假评价、渐变营销 CTA、插画人物故事

参考气质（非抄站）：简洁 docs（清晰层级）× 信息卡目录（卡片一眼可选）。

## 3) 具体改动清单

### A. 首页
1. **英雄区（短）**：品牌标 + 一句话价值 + 2 个主按钮（「按症状判断」→ signs guide；「DIY 还是找人」→ diy-vs-pro）
2. **三列类型入口**：Guide / Compare / Checklist 各一卡，带简单 SVG 图标
3. **内容网格**：现有文章卡加：类型 pill、可选 1 行「你会得到…」、右侧或顶部小示意图
4. **页脚**：略加强品牌一行 + disclosure 链（已有）

### B. 全局视觉
5. **字体**：标题用系统 UI 加粗 + 稍紧字距；正文保持系统字体（零字体授权负担）或可选 `Source Serif`/`IBM Plex` 自托管 OFL
6. **间距**：主区加宽首页至 ~64rem 网格；文章页保持 ~42–48rem 阅读宽
7. **色板**：保留青绿 accent；增加 `--surface-2`、更清晰的边框；callout/warn 保持
8. **深色模式（可选二期）**：`prefers-color-scheme` 或开关；一期可只做浅色加强

### C. 内页模板（不改 MDX 信息架构）
9. Guide/Compare/Checklist 顶栏：类型徽章 + 预计阅读/用途一句
10. 决策树、表格外套更明显的「卡」样式（已有 class，加强阴影/左边线）
11. Checklist：复选视觉加强（打印友好保留）

### D. 移动端
12. 导航改为可折叠或横向滚动 pills
13. 英雄区按钮全宽；卡片单列

## 4) 图片从哪来（许可）

| 来源 | 用途 | 许可 |
| --- | --- | --- |
| **自绘 SVG**（优先） | 通风管截面示意、刷杆、排气帽、DIY vs Pro 分叉 | 自有，可商用 |
| **简单几何插画**（CSS/SVG） | 首页英雄背景纹理（气流线） | 自有 |
| **图标** | Lucide 或 Heroicons（MIT）内联 SVG，不拉整库 CDN 追踪 | MIT |
| **生成图** | 仅当 SVG 不够时；避免真实品牌/假「用户照片」；标注 AI | 生成后自有使用 |
| **禁止** | 盗用 Wirecutter/Amazon/厂商产品图、无授权库存图 | — |

一期建议：**全 SVG + MIT 图标**，零版权纠纷，加载快。

## 5) 工作量与夜更影响

| 项 | 估计 |
| --- | --- |
| 一期视觉（CSS + 首页结构 + 布局组件 + 6–8 个 SVG） | **约 0.5–1 人日** |
| 内页模板润色 | 含在上 |
| 深色模式 | +0.5 人日（可二期） |
| **对夜更模板** | **MDX 字段与章节结构不变**；夜更继续写同模板正文。仅布局/CSS/首页组件变。新页若加 `og`/`cover` 字段为可选，不强制 |

风险：改 `base` 路径下的静态资源路径时注意 `/ventruncheck/` 前缀。

## 6) 过了长什么样（验收标准）

1. 首页 3 秒内能看出：这是 dryer vent 决策目录，有清晰入口，不是「一堵字墙」
2. 每张内容卡可见类型（Guide/Compare/Checklist）+ 标题 + 短描述
3. 至少首页与 1 篇 Guide 有 SVG 示意图（非装饰噪音）
4. 移动端 375px 宽：导航可用、按钮可点、无横向溢出
5. `npm run build` exit 0；push 后 Pages 绿
6. **证据**：改前截图（`docs/redesign-before/`）vs 改后本地 preview / 线上截图
